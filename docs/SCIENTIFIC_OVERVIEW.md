## 1. Контекст и мотивация

Проект FlyWire опубликовал реконструкцию из ~139 000 нейронов и ~54,5 млн синаптов — первый полный коннектом сложного организма. Параллельно в ML стала очевидной проблема катастрофического забывания: нейросеть, обученная задаче A, теряет навыки при обучении задаче B. На пересечении — вопрос: может ли биологическая топология нервной системы служить индуктивным смещением, которое уменьшает забывание?

## 2. Что уже сделано в мире

### 2.1. Коннектом как контроллер
- FlyGM (2026): коннектом дрозофилы в GNN-контроллере, RL на локомоции. Превзошёл MLP, но continual learning не тестировался.
- Eon Systems (2026): полная эмуляция мозга дрозофилы в MuJoCo.
- Yanjin-ai/connectome: отрицательный результат на CartPole — биотопология хуже MLP на реактивных задачах без памяти.

### 2.2. Continual learning и модульность
- EWC (2017): штраф за изменение важных весов. Не использует структуру сети.
- Modular networks: искусственная модульность снижает забывание, но задавалась вручную.
- Нейромодуляция: исследовалась как gating для CL, но не с реальным коннектомом.

### 2.3. Пробел
Никто не проверил, помогает ли биологическая топология коннектома при последовательном обучении нескольким задачам.

## 3. Гипотеза

Основная: Модульная топология зрительного пути дрозофилы при последовательном обучении двум задачам навигации уменьшает катастрофическое забывание по сравнению с графами той же плотности и размера, но без биологической модульности.

H1: Bio забывает меньше, чем degree-preserving rewired (важна конкретная схема связей).
H2: Bio забывает меньше, чем Erdos-Renyi той же плотности (важна структура вообще).
H3: Удаление знаков синапсов (unsigned) ухудшает устойчивость к забыванию (роль тормозных связей).
H4: Эффект на 2K и 8K узлах однонаправлен (масштабируемость).

### Почему зрительный путь
Чёткая иерархия LA -> ME -> LO -> LOP, выраженная модульность, известные функциональные роли, компактный размер (~8K узлов).

### Почему две задачи
T1 (навигация к цели) и T2 (навигация к цели + препятствия) создают контролируемый конфликт: T2 требует подавления поведения из T1.

## 4. Методология

### 4.1. Данные
FlyWire v783, зрительный путь + моторные нейроны, знаковые веса по нейромедиаторам, два масштаба (2K и 8K).

### 4.2. Варианты графа
Bio (signed), Rewired (Maslov-Sneppen), Random ER, Bio (unsigned), MLP (без графа, сопоставимые параметры).

### 4.3. Архитектура
GNN: наблюдение -> сенсорные узлы -> message-passing (`n_steps` по масштабу: 7 для 2K, 5 для 8K — путь сенсоры -> моторы занимает 5-7 и 4-5 хопов) -> моторные узлы -> readout. Топология фиксирована, обучаются веса сообщений; веса рёбер нормируются так, чтобы mean|w| ≈ 0.5.

### 4.4. Среда
2D-навигация (gymnasium): 8 лучей лидара + угол к цели, 3 дискретных действия.

### 4.5. Обучение
PPO (SB3), T1 (200K шагов) -> оценка -> T2 (200K шагов) -> оценка на T1 и T2. Без методов против забывания.

### 4.6. Метрики
Forgetting = R(T1 после T1) - R(T1 после T2). Forward transfer = Steps(T2 после T1) / Steps(T2 с нуля). Final reward.

### 4.7. Статистика
2K: 3 сида x 5 архитектур, Wilcoxon rank-sum. 8K: 1 сид x 2 архитектуры, качественное сравнение.

## 5. Ожидаемые результаты

Если подтверждается: биологическая модульная топология — функциональное индуктивное смещение для CL, тормозные связи как "стены" между модулями.
Если опровергается: биотопология помогает на single-task, но не переносится на CL — поднимает вопрос о недостающих элементах (нейромодуляция, пластичность).
Частичный результат: тонкая картина, какие свойства за что отвечают.

## 6. Значимость

Для коннектомики: первый тест коннектома как готовой архитектуры для CL.
Для continual learning: новый источник индуктивных смещений из биологии.
Для нейробиологии: вычислительное подтверждение функциональной специализации.

## 7. Ограничения

Один подграф (зрение), 2 задачи, коннектом одной особи, 1 сид на 8K, простая 2D-среда, без спайковой динамики, без нейромодуляции.
