# Ограничения 2K-эксперимента и анализ статистической мощности

Документ фиксирует, что именно показал 2K-эксперимент, чего он **не** показал,
и какой объём вычислений нужен для строгого ответа на вопрос гипотезы.
Все числа взяты из файлов `results/metrics/` (см. раздел «Источники данных»),
ничего не пересчитывалось «на глаз».

## 1. Краткое резюме

- 2K-эксперимент выполнен полностью: **15/15 реальных прогонов** (5 архитектур ×
  3 сида), `config_hash 7d6f4e48`, 200 000 шагов PPO на задачу, без `smoke_stub`.
- **Гипотеза не подтверждена.** Ни одна из архитектур не показывает
  систематически большего забывания, чем bio; все 95 % bootstrap-интервалы
  разницы медиан пересекают ноль, Wilcoxon даёт p = 0.827 во всех четырёх
  сравнениях.
- **Забывание близко к нулю у всех архитектур** (медианы в диапазоне
  −1.85 … +0.39 единиц награды), то есть сама пара задач T1 → T2 слабо
  провоцирует катастрофическое забывание.
- Два прогона из 15 (13 %) не сошлись и дают значения порядка −22 и −146 —
  это **срыв обучения, а не забывание**; они искажают mean/std и полностью
  обесценивают статистику, если их не отделить.
- Главное ограничение — **не результат, а мощность**: при n = 3 сида
  вероятность обнаружить реальный эффект размером 1.0 единицы составляет
  всего **0.103**. Корректная формулировка — «нет доказательств пользы
  коннектома», а не «доказано отсутствие эффекта».
- Отрицательный результат относится к **модели** (замороженная топология,
  обучение только весов, две задачи), а не к биологии: механизмы, дающие
  устойчивость в живом мозге, в модель не заложены — см. раздел 10.

## 2. Фактические результаты 2K

### 2.1. Медианы (устойчивые оценки)

Forgetting = R(T1 после T1) − R(T1 после T2); положительное значение — падение
качества на T1 после обучения на T2. Для rewired и unsigned приведены значения
**без выбросов** (n = 2), для остальных — все 3 сида.

| Архитектура | n | Медиана forgetting | IQR | Комментарий |
|---|---|---|---|---|
| bio | 3 | **−1.748** | 2.170 | полный набор |
| rewired | 2 | **+0.101** | 1.116 | без `rewired_2k_seed2` |
| random_er | 3 | **−1.849** | 1.375 | полный набор |
| unsigned | 2 | **+0.386** | 0.238 | без `unsigned_2k_seed3` |
| mlp | 3 | **−1.310** | 0.850 | полный набор |

Источник: `2k_robust.json` → `per_arch_clean`.

### 2.2. Почему нельзя опираться на mean ± std

Сырые mean/std из `2k_summary.json` выглядят драматично, но описывают не
эффект топологии, а два сбойных прогона:

| Архитектура | mean ± std (все сиды) | mean ± std (без выбросов) |
|---|---|---|
| bio | −0.77 ± 2.33 | −0.77 ± 2.33 |
| rewired | −7.31 ± 12.89 | +0.10 ± 1.58 |
| random_er | −1.21 ± 1.48 | −1.21 ± 1.48 |
| unsigned | −48.44 ± 84.57 | +0.39 ± 0.34 |
| mlp | −1.20 ± 0.86 | −1.20 ± 0.86 |

Разница между столбцами — целиком вклад двух точек. Поэтому в тексте статьи
основными следует считать медианы и IQR, а mean/std приводить только с явной
пометкой о выбросах.

### 2.3. Wilcoxon rank-sum

`2k_summary.json` → `tests`: bio vs rewired / random_er / unsigned / mlp —
**p = 0.827** во всех случаях (статистика ±0.218). При n = 3 на группу
минимально достижимый p для двустороннего критерия равен 0.1, то есть тест
физически не способен дать значимый результат; p = 0.827 означает лишь
«выборки полностью перемешаны», а не «эффекта нет».

## 3. Выбросы: срыв обучения, а не забывание

Автодетектор (`2k_robust.json` → `outlier_rule`): выброс = сработал **любой**
из двух детекторов — IQR по объединённому пулу (k = 1.5) **или** MAD
modified z-score (> 3.5) внутри архитектуры, причём MAD применяется только
при n ≥ 5 (при n = 3 MAD-оценка нестабильна).

Найдено 4 аномальных значения в 2 прогонах:

| Прогон | Метрика | Значение | Детектор |
|---|---|---|---|
| `rewired_2k_seed2` | forgetting | −22.14 | IQR |
| `rewired_2k_seed2` | final_reward_t1 | −142.96 | IQR |
| `rewired_2k_seed2` | final_reward_t2 | −124.04 | IQR |
| `unsigned_2k_seed3` | forgetting | −146.08 | IQR |

Интерпретация:

- `rewired_2k_seed2`: R(T1) = −142.96 — политика не выучила первую задачу
  вообще (награда глубоко отрицательная), поэтому «разность до/после T2»
  не является забыванием.
- `unsigned_2k_seed3`: forgetting = −146.08 при нормальных R(T1) ≈ 4.66 и
  R(T2) ≈ 3.33 — аномалия в знаке/масштабе метрики, а не деградация навыка.
- Оба случая — **несошедшееся обучение / коллапс**, а не индикатор системного
  эффекта топологии. Их нельзя молча удалять: в отчёте они приводятся
  отдельно, а все агрегаты даются в двух вариантах (`all` и `clean`).

Доля сбоев: **2 из 15 прогонов (13 %)** — это самостоятельная проблема
стабильности обучения, которую нужно решать до наращивания числа сидов.

## 4. Сравнение bio с контролями

Bootstrap 95 % CI разницы медиан (10 000 ресэмплов, seed 20261105),
`2k_robust.json` → `comparisons_forgetting` → `clean`:

| Сравнение | Δ медиан (bio − контроль) | 95 % CI | p (bootstrap) |
|---|---|---|---|
| bio − rewired | −1.85 | [−3.67, +2.91] | 0.503 |
| bio − random_er | +0.10 | [−2.93, +4.16] | 0.773 |
| bio − unsigned | −2.13 | [−3.07, +1.75] | 0.503 |
| bio − mlp | −0.44 | [−2.16, +3.88] | 0.763 |

**Все интервалы пересекают ноль.** Точечные оценки слегка в пользу bio
(кроме random_er), но ширина интервалов (±2–4 единицы) сравнима с самим
эффектом, поэтому направление нельзя считать установленным.

Для контраста: если считать по всем сидам (`all`), CI для bio − rewired
расширяется до [−3.67, +24.03], а для bio − unsigned — до [−3.07, +147.98].
Один сбойный прогон раздувает интервал в десятки раз — ещё один аргумент
за предварительную фильтрацию коллапсов.

## 5. Анализ мощности

Источник: `2k_power.json` (alpha = 0.05, target power = 0.8, 2000 симуляций
Mann-Whitney, seed 20261105).

### 5.1. Разброс

| Набор | σ forgetting |
|---|---|
| без выбросов (`clean`, n = 13) | **1.43** |
| со всеми прогонами (`all`, n = 15) | **37.59** |

Разница в 26 раз: два коллапса делают распределение настолько тяжёлохвостым,
что мощность не достигает 0.8 **ни при каком** n (в сценарии `all` поля
`n_for_power80_*` равны `null` для всех δ). Практический вывод: сначала
стабилизация обучения, потом увеличение выборки.

### 5.2. Мощность при текущем n = 3 (сценарий `clean`)

| MDE (δ) | Мощность Welch t | Мощность Mann-Whitney |
|---|---|---|
| 0.5 | 0.063 | 0.000 |
| 1.0 | 0.103 | 0.000 |
| 2.0 | 0.263 | 0.000 |

То есть при n = 3 даже эффект в 2 единицы обнаруживается лишь в 26 %
случаев, а эффект в 1 единицу — в 10 %. Mann-Whitney при n = 3 не достигает
номинального уровня 0.05 ни в одной симуляции.

### 5.3. Сколько сидов нужно для power = 0.8

| MDE (δ) | n (Welch t) | n (Mann-Whitney) |
|---|---|---|
| 0.5 | > 60 (при n = 60 мощность 0.477 / 0.401) | > 60 |
| 1.0 | **34** | **40** |
| 2.0 | **10** | **10** |

Вывод: исследование было **сильно недоукомплектовано сидами**. «No evidence
of effect» здесь — не «evidence of no effect»: при n = 3 отсутствие
значимости ожидаемо почти при любом истинном эффекте.

## 6. Ресурсная оценка полного дизайна

Фактические длительности 15 прогонов (`elapsed_seconds` в `2k_*_seed*.json`):
медиана **3.35 ч**, среднее **2.43 ч**, минимум 0.23 ч (MLP), максимум 3.55 ч.
Среднее ниже медианы, потому что MLP в 15 раз быстрее GNN-прогонов; для
планирования GNN-нагрузки корректна медиана.

| Дизайн | Прогонов | Часы (медиана 3.35 ч) | Суток на 1×16 ГБ |
|---|---|---|---|
| 35 сидов × 5 архитектур (MDE = 1.0) | 175 | ~586 | ~24.4 |
| то же, по среднему 2.43 ч | 175 | ~425 | ~17.7 |
| то же + 15–20 % на сбои/перезапуски | 175 | ~675–704 | **~28–29** |
| 35 сидов × 3 архитектуры (bio/rewired/random_er) | 105 | ~352 | ~14.7 |
| 10 сидов × 5 архитектур (MDE = 2.0) | 50 | ~168 | ~7.0 |
| 10 сидов × 3 архитектуры (MDE = 2.0) | 30 | ~101 | ~4.2 |

Оценки консервативны: они используют медиану по всем архитектурам, тогда как
MLP-прогоны занимают ~0.23 ч. Если считать только 4 GNN-архитектуры
(140 прогонов), получается ~469 ч ≈ 19.5 сут.

## 7. Ограничения

1. **n = 3 сида на архитектуру.** Основное ограничение; см. раздел 5.
   Мощность 0.10–0.26 для реалистичных MDE.
2. **2 катастрофических прогона из 15 (13 %).** Срывы обучения, а не
   забывание; они искажают mean/std и делают сценарий `all` непригодным
   для статистики.
3. **8K не даёт статистики.** Планируется 1 сид, только bio vs rewired,
   качественная проверка направления (H4). Текущие `8k_*.json` — dry-run
   заглушки (`config_hash b097c956`, timestamp 2026-09-16), реального
   прогона 8K ещё нет; `8k_summary.json` содержит `n = 1` и
   `p_value = null`.
4. **Forgetting ≈ 0 у всех архитектур.** Пара задач T1 (goto) → T2 (avoid)
   слабо провоцирует забывание: медианы лежат в пределах ±2 единиц награды
   при разбросе того же порядка. Возможен эффект «потолка»: измеряемая
   величина слишком мала, чтобы различать архитектуры.
5. **Один подграф, один коннектом, две задачи, простая 2D-среда** — без
   спайковой динамики и нейромодуляции (см. `docs/SCIENTIFIC_OVERVIEW.md`,
   раздел 7).
6. **Топология фиксирована**, обучаются только веса сообщений и readout;
   выводы относятся к этой конкретной схеме GNN-контроллера.

## 8. Корректная формулировка вывода

> На масштабе 2K нет доказательств того, что топология зрительного пути
> дрозофилы снижает катастрофическое забывание: медианы forgetting у bio и
> контролей статистически неразличимы, все 95 % CI разницы пересекают ноль.
> При этом исследование недостаточно мощное, чтобы исключить малый эффект
> (порядка < 2 единиц награды): при n = 3 мощность составляет 0.10 для
> MDE = 1.0 и 0.26 для MDE = 2.0. Для строгого утверждения «эффекта нет»
> требуется ~34 сида (Welch, MDE = 1.0) или ~40 (Mann-Whitney), либо
> эквивалентный TOST-дизайн с заранее заданной границей эквивалентности.

Чего **нельзя** писать: «доказано, что коннектом не помогает»,
«биотопология не влияет на забывание», «эффект отсутствует». Корректно:
«эффект не обнаружен», «данных недостаточно для вывода об отсутствии
эффекта».

## 9. Рекомендации

1. **Если продолжать в текущей парадигме** — компромиссный вариант:
   **10 сидов** на архитектуру (MDE = 2.0, power ≈ 0.84 для Welch).
   Это ~168 ч ≈ 7 сут на 16 ГБ для 5 архитектур или ~101 ч ≈ 4.2 сут для 3.
2. **Если нужен строгий отрицательный результат** — перейти к
   **TOST / тесту эквивалентности** с заранее зафиксированной границей
   (например, |Δ| < 1.0 единицы награды). Это меняет постановку: нужно
   доказать, что эффект *меньше* границы, а не что он равен нулю; число
   сидов определяется той же мощностью (~34–40 при границе 1.0).
3. **До наращивания сидов — стабилизировать обучение.** 2/15 коллапсов
   (13 %) при 175 прогонах дадут ~23 сбойных точки; они разрушают мощность
   (σ 1.43 → 37.59). Минимум: детектор несошедшихся прогонов по
   `final_reward_t1` и автоматический перезапуск с другим сидом.
4. **8K оставить качественной проверкой** направления (H4): 1 сид,
   bio vs rewired, без статистических утверждений. Полноценный 8K-дизайн
   с n ≥ 10 на 96 ГБ-сервере — отдельное решение по бюджету.
5. **В тексте статьи** всегда приводить медианы/IQR как основные оценки,
   mean/std — с пометкой о выбросах, и явно указывать достигнутую мощность.

## 10. Границы применимости: результат относится к модели, а не к биологии

### 10.1. Что именно проверялось

Эксперимент проверяет узкую, но чётко определённую гипотезу: даёт ли **сама
топология** графа устойчивость к забыванию при следующих допущениях:

- топология (`edge_index`) **заморожена**;
- обучаются только веса сообщений GNN и проекция/readout;
- две задачи (`goto → avoid`), простая 2D-среда, PPO 200 000 шагов;
- **нет** синаптической пластичности, нейромодуляции, структурной
  пластичности, спайковой динамики и консолидации.

При этих допущениях ответ: **нет, топология сама по себе не даёт устойчивости**
(см. разделы 2–5).

### 10.2. Чего этот результат НЕ доказывает

Он **не** доказывает, что коннектом не важен для continual learning *in vivo*.
Он показывает, что «топология без механизмов обучения» не создаёт
устойчивости. Это два разных утверждения, и в отчёте их нельзя смешивать.

### 10.3. Какие механизмы выкинуты из модели

| Механизм | Роль в устойчивости к переучиванию | Есть в модели |
|---|---|---|
| Синаптическая пластичность (STDP, гомеостаз) | консолидация, защита важных синапсов | нет |
| Нейромодуляция (дофамин/серотонин) | переключение режимов обучение/консолидация | нет |
| Структурная пластичность | рост/удаление связей под задачу | нет |
| Спайковая динамика | временная динамика, рабочая память | нет |
| Сон / офлайн-консолидация | переигрывание, перенос | нет |
| Развитие / критические периоды | формирование схемы | нет |

Именно эти механизмы в живом мозге и обеспечивают устойчивость к
переучиванию; в модели они отсутствуют, поэтому отрицательный результат
характеризует **класс моделей «замороженная топология + обучение только
весов»**, а не биологический коннектом.

### 10.4. Потолок forgetting — отдельное ограничение дизайна

Forgetting ≈ 0 у всех архитектур (раздел 2) означает, что пара задач
`goto → avoid` **вообще не вызывает забывания**. Мы пытаемся измерить
«устойчивость к забыванию», которого нет: нечего сопротивляться. Это
ограничение **дизайна задач**, а не свойство топологии. Чтобы проверить
устойчивость, сначала нужно создать забывание (больше задач в
последовательности, сложнее T2, длиннее цепочка), и только потом спрашивать,
снижает ли его топология.

### 10.5. Что нужно, чтобы проверить биологическую гипотезу

1. **Harder task design** — последовательность задач с реальной
   интерференцией, чтобы forgetting был заметно > 0.
2. **Механизмы обучения** — пластичность, нейромодуляция, структурные
   изменения (а не только веса сообщений).
3. **Спайковая модель** — если важна временная динамика.
4. **Больше задач и длиннее обучение** — чтобы консолидация успевала
   проявиться.

Это отдельный, существенно более дорогой проект; наращивание числа сидов
в текущей постановке его не заменяет.

### 10.6. Корректная формулировка для статьи

> В данной модели (замороженная топология, обучение только весов, две задачи)
> топология коннектома не снижает катастрофическое забывание. Это
> отрицательный результат для класса моделей «топология + обучение только
> весов», а не для биологического коннектома как такового; проверка
> биологической гипотезы требует включения пластичности/нейромодуляции и
> дизайна задач, порождающего забывание.
