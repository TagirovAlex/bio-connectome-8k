# Данные

## Сырые данные (не в git, ~290 МБ)

Источник — открытые данные проекта **FlyWire** (коннектом взрослой
дрозофилы, версия **v783**). Файлы лежат в `data/raw/` и исключены из
репозитория из-за размера.

| Файл | Размер | Содержимое |
|---|---:|---|
| `connections.csv` | ~261 МБ | синаптические связи (пре-/пост-нейрон, `syn_count`, нейромедиатор) |
| `classification.csv` | ~9.5 МБ | классификация нейронов по типу/региону |
| `neuron_annotations.csv` | ~7.8 МБ | координаты и атрибуты нейронов |
| `nt.csv` | ~8.2 МБ | нейромедиаторы |
| `consolidated_cell_types.csv` | ~3.6 МБ | консолидированные типы клеток |

Подробный реестр источников и дат — [`data_registry.md`](data_registry.md).

### Как получить сырые данные

1. Скачать CSV FlyWire v783 с [flywire.ai](https://flywire.ai) (или через
   `src/data/download.py`, если установлен `caveclient`).
2. Положить их в `data/raw/`.

## Готовые графы (в git, ~14 МБ)

Собранные графы для экспериментов лежат в `data/processed/*.pt` и **включены
в репозиторий**, чтобы 2K/8K-прогоны воспроизводились без повторной сборки из
сырых CSV.

| Файл | Узлы | Рёбра | МБ |
|---|---:|---:|---:|
| `bio_2k.pt` | 2000 | 42 023 | ~1.0 |
| `rewired_2k.pt` | 2000 | 42 023 | ~0.9 |
| `random_er_2k.pt` | 2000 | 42 023 | ~0.8 |
| `unsigned_2k.pt` | 2000 | 42 023 | ~0.9 |
| `bio_8k.pt` | 8000 | 224 567 | ~5.4 |
| `rewired_8k.pt` | 8000 | 224 567 | ~4.6 |

Структурные метрики всех графов — [`../results/metrics/graph_stats.json`](../results/metrics/graph_stats.json).

### Пересборка графов из CSV

```bash
python scripts/01_build_graphs.py --rebuild
```

## Валидация графов

При сборке проверяется: нет изолированных узлов, нет NaN-весов,
`sensory_mask ≥ 50`, `motor_mask ≥ 20`, модульность bio > 0.3
(см. [`docs/experiment_plan.md`](../docs/experiment_plan.md)).
